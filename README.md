How to Fish 辅助工具 / Trainer
这是为《How to Fish》制作的便捷辅助工具，主要用于调整单人游戏体验、减少重复操作并方便测试不同玩法。界面支持中文，功能可以随时开启、关闭或调整。
This is a convenience trainer made for How to Fish. It is mainly designed to customize the single-player experience, reduce repetitive actions, and make it easier to test different gameplay settings. The interface supports Chinese, and features can be enabled, disabled, or adjusted at any time.
主要功能 / Main Features
- 伤害倍率调整
  Adjustable damage multiplier
- 玩家血量倍率
  Adjustable player health multiplier
- 提高极品动物出现概率
  Adjustable high-quality animal spawn chance
- 赌博成功概率调整
  Adjustable gambling success rate
- 自定义转盘皮肤品质
  Selectable roulette skin quality
- 辅助瞄准及速度调节
  Aim assist with adjustable aiming speed
- 使用右 Ctrl 快速开启或关闭辅助瞄准
  Press Right Ctrl to quickly enable or disable aim assist
- 不适用于当前模式的功能会自动锁定或显示为灰色
  Features unavailable in the current game mode will be automatically locked or grayed out
安装方法 / Installation
1. 下载并解压 ZIP 文件。
   Download and extract the ZIP archive.
2.解压后的文件夹运行 install.ps1
然后安装器应该会自动寻找 Steam 游戏路径
3. 从 Steam 正常启动游戏。
   Launch the game normally through Steam.
4. 进入游戏后打开辅助面板并设置需要的功能。
   Open the trainer panel in-game and configure the desired features.
如果还是不会安装可以去网页看教程在网页链接里
注意事项 / Important Notes
本工具主要为单人和离线游戏体验设计。游戏更新后，部分功能可能暂时失效，需要等待兼容版本。安装前建议备份存档，请勿将本工具用于破坏其他玩家体验或未经同意的多人游戏。
This tool is primarily designed for single-player and offline gameplay. Some features may temporarily stop working after a game update until a compatible version is released. Backing up your save files before installation is recommended. Do not use this tool to disrupt other players or in multiplayer sessions without everyone’s consent.
