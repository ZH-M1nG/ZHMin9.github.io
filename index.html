Features / 主要功能

Installation / 安装

三步完成安装。

安装前建议备份存档。首次加载 BepInEx 时，游戏启动可能会稍慢。

下载并解压

下载 ZIP 后完整解压到一个普通文件夹，不要直接在压缩包预览中运行安装器。

运行安装脚本

在解压目录中右键或通过 PowerShell 运行 install.ps1。安装器会自动识别常见路径。

powershell -ExecutionPolicy Bypass -File .\install.ps1

从 Steam 启动

正常启动游戏，进入存档后按 Insert 打开面板。需要卸载时运行 uninstall.ps1。

兼容性说明 / Compatibility: 已校验 Unity 6000.4.4f1 与 BepInEx 5.4.23.5。游戏更新后如出现“不兼容”或功能失效，请先卸载并等待适配，不要在新版本上强行使用。
